## Introduction

Time-series datasets ordinarily represent a process as ordered values. The behaviors studied within those values—cycles, transitions, episodes, and accumulations—often remain implicit. An analyst may be able to see that a waveform repeats, that a process rises and falls, or that one interval differs from another, but those recognitions are not yet computational objects. The data do not inherently state where an occurrence begins, which observations belong to it, whether it is complete, or which measurements should be attributed to it.

This representational gap produces repeated work. Before asking how long cycles last, whether their amplitudes change, which occurrences are asymmetric, or how behavior differs among subjects or runs, an analysis must first identify boundaries and assign observations to occurrences. Similar boundary logic is often reconstructed separately for visualization, statistical summaries, feature engineering, anomaly detection, and downstream models. When that logic remains embedded in notebooks or isolated feature calculations, behavioral identity and construction provenance are difficult to reuse or inspect.

Existing time-series tools address important parts of this problem. Peak detectors locate extrema, segmentation methods divide sequences, feature libraries calculate numerical summaries, and databases retrieve observations over specified intervals. These capabilities do not by themselves define a persistent behavioral representation. A detected peak is a landmark, not a complete cycle. A duration is interpretable only after the occurrence whose duration is being measured has been bounded. A query for “long oscillations” presupposes that oscillations already have identities, boundaries, and durations.

FeatureGraph addresses this prerequisite layer. It is a deterministic framework for transforming ordered observations into explicit, temporally bounded behavioral objects. The framework separates raw observations, sample-level states and events, and object-level summaries. States express local conditions. Events mark changes in those conditions. Ordered configurations of events define object boundaries and internal landmarks. Once an object has an identity and interval, its properties can be calculated and exposed in a table with one row per occurrence.

The central contribution is therefore representational rather than a new formula for amplitude, duration, or area. These measurements are well known. FeatureGraph supplies the explicit object to which they belong and retains the construction evidence required to interpret them. The result can be inspected at sample level, summarized at object level, and queried using ordinary tabular operations. Downstream software can consume the representation without repeatedly reconstructing the behavior from raw observations.

The alpha implementation, FeatureGraph v0.1.0a1, realizes this approach for trough–peak–trough oscillations and for accumulations constructed within those oscillation boundaries. Directional differences define rising and falling states. State changes yield extrema events. Consecutive troughs with an intervening peak define oscillation identities. Each complete object receives structural and geometric properties, while boundary-truncated constructions retain an explicit completeness status. Wave-derived accumulation demonstrates composition: an existing oscillation supplies the interval and baseline context for a cumulative representation.

We evaluate the alpha in two complementary ways. A synthetic benchmark supplies known boundaries and properties, allowing exact-recovery verification and a held-out noise study. FeatureGraph is compared with a SciPy peak-based baseline under fixed operating points selected on disjoint tuning seeds. Detection, interval overlap, localization, property error, parameter sensitivity, and uncertainty are reported separately. The comparison is not intended to establish FeatureGraph as a universally superior oscillation detector. It tests whether the alpha construction preserves known structure and reveals the conditions under which its directional-state detector becomes unreliable.

Cross-domain demonstrations then apply the same construction to BIDMC respiration and Tennessee Eastman reactor temperature. The two signals have unrelated physical meanings, units, and scientific contexts. Their commonality is narrower: both can be operationally represented as repeated directional objects with start, peak and end landmarks. The demonstrations test whether one computational schema can survive this change in domain while retaining signal-specific grouping, preprocessing, and provenance.

This paper makes four contributions:

1. It defines a deterministic representational progression from ordered observations to states and events, then to bounded behavioral objects.
2. It presents an inspectable alpha implementation for oscillations and wave-derived accumulation, including object identity, completeness, intrinsic properties, provenance, and a query interface.
3. It evaluates the implementation against synthetic ground truth, distinguishing detection reliability, boundary semantics, and conditional property accuracy.
4. It demonstrates reuse of the same object schema across physiological and industrial-process signals without claiming that the underlying physical behaviors are equivalent.

The scope is deliberately constrained. FeatureGraph does not infer every scientifically meaningful state, eliminate parameter selection, or replace specialized detectors. A user must operationally specify a construction appropriate to the signal, and the resulting object table is only as reliable as the states and boundaries from which it is built. The framework’s claim is that once such distinctions are specified, they can be made explicit, reproducible, inspectable, composable, and available to computation.

The remainder of the paper first defines the framework and its representational levels. It then describes the alpha implementation, the synthetic evaluation protocol and results, and the two cross-domain demonstrations. The discussion considers the relationship between detection and representation, the value of retained provenance and object-level queryability, and the limitations of the present alpha architecture.
